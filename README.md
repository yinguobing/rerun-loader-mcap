# rerun-loader-mcap
Rerun data loader plugin for MCAP.

Visualize MCAP content in Rerun viewer.

## Install
Download the latest installation package from the [release](https://github.com/yinguobing/rerun-loader-mcap/releases/) page. 

Install
```bash
dpkg -i rerun-loader-mcap_VERSION.deb
```

## Usage
Open Rerun viewer
```bash
rerun
```

Drag and drop the MCAP file in the viewer window.
